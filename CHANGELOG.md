## [Unreleased]

## [0.3.0] - 2026-10-07

### Добавлено
- Карта Foundry District 60 × 44 м: цех с мостиком и рампой, двор, насосная, генераторная, сервисные тоннели и погрузочная площадка.
- Практика 3 на 3 (игрок и пять ботов), ротация четырёх целей каждые 60 секунд, бонус за непрерывное удержание.
- Архивы игры с лаунчером для Windows x64, Linux x64 (AppImage) и macOS arm64; выпуск релизов через GitHub Actions.
- Docker-образ сервера (`linux/amd64`, `linux/arm64`) в GitHub Container Registry и `docker-compose.yml`.
- CI: тесты сервера и Rust-ядра, сборка клиента на трёх ОС, сборка и проверка Docker-образа.

### Изменено
- Архитектура разбита по слоям: сервер (`game/`, `world/`, `network/`, `match/`, `persistence/`), Rust-ядро (`mesh/`, `actor/`, `atlas`, `ffi`), клиент (`net/`, `game/`, `input/`, `ui/`, `render/`). Игровая логика и рендер побитово совпадают с прежней версией.
- Шейдеры вынесены в `client/app/shaders`, модели получили имена (`BsModel`) вместо номеров.
- Единая версия 0.3.0 у сервера, клиента и ядра.

### Удалено
- Неиспользуемый 2.5D-рейкастер (`bs_cast`, `bs_wall_pixel`, `bs_version`) из Rust-ядра.

### Исправлено
- Обращение к уничтоженным данным при закрытии окна клиента во время активного соединения.
- После возврата в меню клиент больше не обрабатывает уже полученные строки от старого соединения.

## [0.2.0] - 2026-10-06 (без отдельного релиза)

### Добавлено
- Полигональный 3D-рендер на OpenGL: объектная карта из выпуклых объёмов, запечённое освещение, нарисованные материалы с mipmaps.
- Скелетный боец (13 костей, взвешенная деформация), анимации ходьбы, прыжка и отдачи; экспорт OBJ/SMD.
- Прыжки, бег, вертикальное прицеливание, потолки и опора по 3D-геометрии на сервере.
- Аптечки, предупреждение о захвате цели башней, ограниченная скорость поворота и задержка реакции ботов.

### Изменено
- Сервер переписан с Go на Elixir/OTP; результаты матчей хранятся в Mnesia. Протокол v1 сохранён.
