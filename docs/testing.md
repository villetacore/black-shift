# Тестирование

## Автоматические проверки

| Команда | Что проверяет |
|---|---|
| `cd server && mix test --warnings-as-errors` | 70 тестов. Симуляция: физика, прыжки и потолки, стрельба по 3D-объёмам, режимы Warden, ускорение Ranger и его окончание, возрождение, башни и ядра, захват и затухание реле, предупреждение ротации, бонус волны, аптечки, поведение ботов, полный матч ботов до конца. Мир: геометрия, мостик, рампа, лучи, связность навигации. Mnesia: запись и чтение после перезапуска. Сеть: реальные TCP-клиенты, подбор 1 на 1, повторная очередь, изоляция падения матча, некорректный ввод |
| `cd client/core && cargo test` | Модели триангулированы, нормали единичные, идентификаторы моделей, границы FFI-буферов, веса и иерархия костей, деформация при ходьбе |
| `cargo clippy --all-targets -- -D warnings` | Статический анализ Rust |
| `scripts/build.ps1 -TestClient` | Нативный QtTest: запускает собранный release сервера и настоящий OpenGL-клиент, проверяет прыжок (Space), движение (W), рывок (Q), остановку после Esc и выход через Enter. Отчёт — `build/native-test.txt` |

CI (`.github/workflows/ci.yml`) выполняет тесты сервера и Rust, собирает клиент на Windows, Linux и macOS, собирает Docker-образ сервера и проверяет, что контейнер отвечает по протоколу. Нативный тест в CI не запускается: ему нужен интерактивный рабочий стол с OpenGL 2.1.

## Нативный тест

Тест открывает окно. Пока он идёт, окно нельзя сворачивать и перекрывать: потеряв фокус, игра отпускает управление (так задумано), и проверка движения не пройдёт.

Дополнительные снимки:

- `BLACKSHIFT_TEST_SCREENSHOT=path.png` — кадр из матча;
- `BLACKSHIFT_MAP_PREVIEW=path.png` — пять статичных видов карты: двор (`path.png`), насосная (`.pump.png`), сервисные тоннели (`.service.png`), галерея (`.gallery.png`) и погрузка (`.loading.png`). Они детерминированы, поэтому изменения рендера удобно проверять попиксельным сравнением с эталоном.

Для Foundry Heights набор сервера расширен до 45 тестов: отдельные слои под галереей и на ней, маршруты ко всем реле на высоте, реальный подъём бота, высота дрона, запрет захвата и подбора аптечки через перекрытие. Сетевой тест принимает увеличенное сообщение карты.

Снимки без теста: `blackshift.exe --practice --screenshot game.png` и `blackshift.exe --menu-screenshot menu.png`. Для `QOpenGLWidget` нужна платформа `windows`, `offscreen` не подходит.

## Сохранность базы между запусками

`scripts/check-persistence.exs` пишет результат в одном экземпляре BEAM и читает его в другом с тем же `BS_DB_DIR`:

```sh
cd server
BS_DB_DIR=/tmp/bs-probe BS_PROBE_PHASE=write mix run ../scripts/check-persistence.exs
BS_DB_DIR=/tmp/bs-probe BS_PROBE_PHASE=read  mix run ../scripts/check-persistence.exs
```

## Замер темпа

Замер игрового темпа: из `server/` выполнить
`mix run --no-start scripts/gameplay_benchmark.exs`.
Это пять полных детерминированных матчей 3 на 3 со смешанными классами и разными
идентификаторами ботов (влияют на неточность прицеливания). JSON в stdout содержит
время первого захвата, число захватов и смен владельца (без ротаций), длительность,
окончание по таймеру, счёт, разницу счёта и убийства. Прогресс выводится в stderr.
Прогон проверяет симуляцию; он не заменяет тест баланса с живыми игроками.

## Не проверено

- реальные интернет-подключения между разными компьютерами;
- нагрузочная ёмкость;
- запуск клиента на Linux и macOS. Linux-сборка и AppImage проверены в контейнере Ubuntu 24.04, но без дисплея; macOS собирается только в CI;
- долгосрочный баланс.

### Industrial expansion

`game/liquid_test.exs` проверяет границы воды, плавучесть, мелководье, выход
через ступени бассейна, урон и перекрытие дроби. Нативный тест проверяет
затухание отдачи и сброс анимации смерти после возрождения.
При `BLACKSHIFT_MAP_PREVIEW` дополнительно сохраняются `.water.png`,
`.underwater.png`, `.generator.png`; после кадров проверяется `glGetError`.

### Физика, оружие и ИИ

`physics_test.exs`: разгон и торможение, инерция прыжка, гашение скорости стеной, присед
и запрет вставать без места над головой, урон от падения. `combat_test.exs`: зоны
попадания, спад урона, магазин и перезарядка (в том числе по патрону), отдача и разброс,
отбрасывание, компенсация лага по `view_tick`, рывок как импульс. `bot_test.exs`: поле
зрения, слух, память об атакующем, перезарядка, стрейф, «доводка» прицела, сглаживание
маршрутов. Нативный тест учитывает, что рывок длится 4 тика, а остановка — около 0,25 с.
