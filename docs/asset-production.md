## Модели

Геометрия создаётся Rust-кодом в `client/core/src/mesh/expansion.rs` и сразу используется клиентом через C ABI. Это реальные игровые меши, не изображения моделей.

В этой итерации доработаны:
- SM-9 — 532 треугольника;
- SG-12 — 520 треугольников;
- пульт — 228 треугольников;
- генератор — 224 треугольника.

Добавлены детали силуэта, прицелы, планки, спусковые скобы, резиновые накладки и панели. Коллизионные объёмы карты не изменены.

Экспорт для внешних редакторов:

```sh
cargo run --manifest-path client/core/Cargo.toml --example export_assets
```

OBJ используют `assets/models/industrial.mtl`, который ссылается на новый атлас. Правка экспортированных OBJ не меняет меши в игре.

## Звук

12 оригинальных эффектов синтезируются Rust-программой без сторонних записей и сервисов. WAV: PCM signed 16-bit, mono, 44100 Hz. Генератор детерминирован; шум, огибающие и тональные компоненты задаются кодом.

```sh
cargo run --manifest-path client/core/Cargo.toml --example generate_audio
```

| Файл | Назначение |
|---|---|
| smg.wav / shotgun.wav | Подтверждённые выстрелы |
| step.wav | Шаги на земле |
| reload.wav | Начало перезарядки |
| hit.wav / kill.wav | Подтверждение попадания / убийства |
| hurt.wav | Получение урона |
| dash.wav / pulse.wav | Применение способности |
| relay.wav | Смена точки или владельца реле |
| warning.wav | Предупреждение за 15 секунд до ротации |
| victory.wav | Завершение матча |

Клиент использует Qt Multimedia и собственный стереомикшер на 32 голоса. Для пространственных событий панорама зависит от направления взгляда, громкость — от расстояния (радиус слышимости 24 м). События выявляются по изменению последовательных серверных снимков. Первый снимок, дубликаты и возврат в меню не воспроизводят историю заново.

Ограничения: нет акустической окклюзии стенами, отдельных звуков материалов пола, музыки и динамической смены аудиоустройства. Начальный набор звука требует прослушивания и балансировки на разных наушниках. Микшер выбирает stereo PCM 44.1 kHz либо частоту устройства (Int16/Float) с пересчётом сэмплов. При отсутствии совместимого устройства игра продолжает работу без звука и пишет предупреждение.

## Проверка

Автоматический тест микшера проверяет тишину первого снимка, правый канал для источника справа, отсутствие повтора события, нулевую громкость и очистку истории. Проверка мешей валидирует треугольники и нормали. Нативный тест дополнительно запускает OpenGL-клиент против настоящего сервера.
